Embedded Messaging Test Page

Instructions

This page is set up to test Salesforce Embedded Messaging for Web.

The chat button should appear in the bottom-right corner of the page.

Test Scenarios

  • Click the chat button to start a conversation
  • Test pre-chat form (if configured)
  • Test bot interaction
  • Test agent transfer
  • Test file attachments (if enabled)

Setup Checklist

  • Add https://mchandler.github.io to CORS Allowlist in Salesforce Setup
  • Add scrt2 domain to CSP Trusted Sites if needed
  • Ensure Messaging Channel is active
  • Have an agent available in Omni-Channel (for transfer testing)
